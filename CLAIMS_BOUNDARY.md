# Claims Boundary

## Permitted Claims

This repository may support claims that:

- public control-task data contain reproducible behavioural heterogeneity;
- stable individual differences can be separated from session or window deviations;
- registered contrasts expose structure beyond common background variation;
- dynamic state structure adds prediction beyond static profile baselines;
- APC mechanism parameters interact with latent state as predicted;
- synthetic recovery can distinguish candidate mechanisms under realistic data quality;
- a frozen public-data model transports prospectively to Attention Coach.

## Prohibited Claims

This repository must not be used to claim that:

- Trident states are established brain states;
- individual users can be diagnosed or clinically routed;
- neural criticality has been directly measured;
- Attention Coach has validated clinical benefit;
- intervention effects are proven before preregistered prospective tests pass.

## Falsification Rule

A successful scientific outcome may weaken or reject the Trident architecture. Simpler models should be preferred when they match or outperform the richer architecture on held-out prediction, calibration, robustness and recovery.
