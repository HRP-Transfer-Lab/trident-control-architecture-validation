# Protocol

## Objective

Evaluate whether a dynamic Trident control-state architecture explains behavioural heterogeneity, within-person change, persistence, transitions, vigilance coupling and future behaviour better than simpler baselines.

## Model-Selection Principle

The preferred model is whichever survives:

- external prediction;
- participant- and dataset-isolated validation;
- contrastive falsification;
- synthetic recovery at realistic sample sizes;
- prospective transport to Attention Coach.

## Phases

### Phase A

1. Freeze existing ACDC and paired-control-vigilance outputs.
2. Implement normative trait-state residuals.
3. Run M0-M4 static model tournament.
4. Run registered contrastive analyses.
5. Add participant- and dataset-isolated scoring.

### Phase B

1. Fit M5 dynamic state-space models.
2. Add transition, dwell and re-entry tests.
3. Run six-world synthetic model recovery.
4. Add public datasets needed for Signal, Evidence, Commit and Predictive Calibration identification.

### Phase C

1. Train CVAE only if sample-size and recovery gates pass.
2. Add graph contrastive learning only after transition graphs are stable.
3. Freeze the surviving model.
4. Transport the frozen model prospectively to Attention Coach.

## Required Outputs

- frozen input manifests;
- feature schema and leakage audit;
- participant-level validation splits;
- model-comparison tables;
- contrastive decomposition reports;
- dynamic topology summaries;
- synthetic recovery reports;
- Attention Coach transport report.
