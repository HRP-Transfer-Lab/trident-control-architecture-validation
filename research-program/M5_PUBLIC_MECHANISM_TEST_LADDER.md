# M5/M6 Public Mechanism Test Ladder

**Status:** pre-analysis protocol

This document freezes the staged order for moving from public-data readiness
toward real-data mechanism analysis. No model is fit by this document.

No confirmatory Trident-G, APC, PACE, neural-criticality, cusp or transfer
claim is authorised.

## Machine-Readable Contract

```text
config/public_mechanism_test_ladder_v1.yaml
```

This ladder consumes:

```text
config/hrp_stack_variable_registry_v2.yaml
research-program/M5_PUBLIC_MECHANISM_VARIABLE_SUPPORT_MATRIX.csv
```

## Stage 1: K / C_signal / Vigilance

Question:

```text
Can control and readiness be separated?
```

Primary variables:

```text
K
C_signal
V
Y_behavior
```

The first real-data candidate analysis may compare:

```text
K only
K + C_signal
K + V
K + C_signal + V
K + C_signal x V
```

PACE, dynamic-regime labels, transfer outcomes, confidence calibration and
evidence-updating claims remain excluded from this first stage.

## Stage 2: PACE Expression

Question:

```text
Do regulated / brittle / compensatory / overloaded expressions add predictive
structure beyond continuous K/C/V?
```

This stage is gated after Stage 1 review. PACE is descriptive only. Labels must
be derived inside training folds and must not be treated as natural kinds or
forced into four profiles.

## Stage 3: Dynamic Trajectories

Question:

```text
Are reproducible adaptive / locked / scattered regimes present beyond static
PACE and vigilance?
```

This stage is gated after Stage 2 review. Candidate dynamic labels remain
neutral. Dynamic candidates must beat static controls on held-out prediction
and report reproducibility across sources or sessions before richer regime
claims are entertained.

## Stage 4: Behavioural Criticality-Language Test

Question:

```text
Does the dynamic geometry have the specific behavioural signatures needed to
justify near-critical / subcritical / supercritical language?
```

This stage is gated after Stage 3 review. It is not a neural criticality test.
Allowed interpretation is limited to behavioural dynamic analogues, and only if
simpler AR, HMM/HSMM and static alternatives have been scored.

Required signatures include:

```text
transition-sensitive recovery
reproducible dwell and re-entry structure
hysteresis or path dependence beyond AR nulls
adaptive response to perturbation distinct from noise
separation from generic HMM/HSMM and AR models
source or session transport of geometry
```

Forbidden interpretations:

```text
neural criticality
brain critical zone
literal cusp without a registered cusp competitor
subcritical / near-critical / supercritical labels before Stage 3 passes
```

## Boundary

The staged order is:

```text
K/C_signal/V
  -> PACE expression increment
  -> dynamic trajectories
  -> behavioural criticality-language test
```

Later stages may fail. A failure blocks escalation rather than motivating a
post-hoc rewrite of earlier variables, support thresholds or model definitions.
